# Explain Action

1. Read current-fix.md to understand what was fixed
2. Run `git diff development --name-only` to get list of files changed
3. For each file created or modified:
   - Show the file path
   - Give a 1-2 sentence explanation of what changed and why
   - Highlight the specific bug fix (before vs after behavior)
4. End with a brief summary of the root cause and how the fix resolves it

## Output Format

## Files Changed

**path/to/file.swift** (modified)
What changed and why — focus on the bug fix, not general description.

## Root Cause & Fix

Brief explanation of what was wrong and how the change addresses it.
